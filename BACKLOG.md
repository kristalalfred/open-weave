# Backlog

Open work lives in `backlog/`. Run `just board` to list it. Each item records a
current gap, its evidence, and a verifiable completion condition. Remove
completed or invalid items.

open-weave controls media routing through adapters. Scheduling and entitlements
belong to applications. Encoding, transcoding, bonding and merging belong to
media runtimes.

Not scheduled: additional capture inputs, WebRTC links between Strom nodes,
mixed-transport fan-out, protocol plugins, port coordination with other
orchestrators, and automatic format conversion.
